# Munna Ram Photography

A responsive portfolio website for **Munna Ram**, a professional photographer with more than 10 years of experience at Marine Drive, Mumbai.

The site introduces his photography services, displays portfolio images, lists print and digital copy prices, and lets customers start a booking enquiry through WhatsApp.

## Features

- Photography portfolio for portraits, couples, families, and events
- Pricing for printed and digital photo copies
- Responsive layout for desktop and mobile
- Mobile navigation menu
- Booking enquiry form that opens a pre-filled WhatsApp message
- Direct phone and WhatsApp contact links
